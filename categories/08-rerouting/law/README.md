# Rerouting legal evidence

[Highway Code 150](https://www.gov.uk/guidance/the-highway-code/general-rules-techniques-and-advice-for-all-drivers-and-riders-103-to-158) warns that satellite-navigation and congestion-warning systems can distract drivers.

It does not prescribe rerouting savings, offer timing, distances, cooldowns, or GPS thresholds. Those AI-recommended app choices are checked only in `../decisions/`. No distinct executable legal rule has been identified for this category; do not count the source citation as an executed law test.
