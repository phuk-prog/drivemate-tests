# J27-03-A/B — actual Manchester roundabout graph pretest (27 October 2026)

## Source, test scope and failure criterion

This test replaces an exclusively synthetic acceptance assumption with a
**source-derived test** using the app's own checked-out bundled
`app/src/main/assets/greater-manchester.dmnpack`. The DMN pack is generated
from real UK OSM roads; the test selects actual allowed tagged roundabout edges
in the Stockport/M60/A560/A5145 region and picks original mapped inbound,
circulating and outgoing edges. It does **not** construct artificial nodes or
street segments, nor rely on the navigation engine's own chosen end point as
the expected ring exit.

The pretest performs two independent **map-to-engine consistency** assertions:

1. `NavigationEngine.maneuverEnd(roundabout)` must not precede the actual
   node where the route leaves the map's tagged roundabout edges.
2. At exact GPS fixes generated by interpolation on the same real OSM graph's
   ring edges, `Progress.onRoundabout` remains true and the active instruction
   is a roundabout exit instruction, not the following street turn.

Both checks require at least **two geographically distinct Stockport
roundabouts** and at least **five real ring-internal replay fixes**. The
graph-derived exit is never substituted for an independently checked actual
legal or painted exit. Graph OSM way/node IDs are included on assertion failure
so the owner can obtain dated official corroboration. Source data may still be
wrong/outdated: the final legality, lane arrows, exact driver's journey and
screen/rendering results are explicitly **unknown** until checked separately.

The test fails rather than claiming success if the bundled pack is missing or
insufficiently sampled. Exact app SHA and test SHA are in GitHub Actions;
historical run results remain preserved. Nothing is uploaded from the
driver's private screenshots, device or journey.
