# Category 9 official/legal references

Highway Code rule 144 requires due care and attention; National Highways manages England's strategic road network, not all UK roads. See `drivemate-app/register/09-traffic.md` for current official references. A traffic feed, ETA or route colour cannot establish that a road is legally open or safe.

There is no identified statutory requirement mandating this product's traffic colours, feed-expiry intervals, route delay representation or API budget. Those are explicitly decision checks, never law tests. No tautological executable test is added to pretend that a general duty of care can be proved by a unit assertion. Existing legal guidance/sign/closure checks remain in the combined suite; legal/UI acceptance and physical behavior are not claimed passed here.
